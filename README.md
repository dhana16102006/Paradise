
# Paradise Nursery

Paradise Nursery is a React-based plant shopping website built as a Coursera project.

## Features
- Landing page with Get Started button
- About Us page
- Plant product listing
- Add plants to shopping cart
- Increase or decrease quantities
- Remove items from cart
- Calculate cart subtotal

## Technologies
- React
- JavaScript
- CSS
- Vite

## Run the project
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.
